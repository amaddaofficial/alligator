# 악어악어 점령

아이가 연필로 그린 악어들이 토성을 지키는 가로형 타워디펜스. 냥코대전쟁식 웨이브 전투 끝에 직접 조작하는 보스전이 붙어 있다.
한 장짜리 웹 게임(`index.html`)이라 어디서든 열면 바로 돌아간다. 폰은 옆으로 돌려서.

## 바로 플레이

`index.html`을 브라우저로 열면 끝. GitHub Pages가 켜져 있으면 https://amaddaofficial.github.io/alligator/ 에서 바로 열린다.

링크를 카카오톡 등에 보내면 `og.png`(아이 손글씨 제목 + 악어)와 제목이 미리보기로 뜬다. 홈 화면에 추가하면 `icon.png`가 아이콘이 된다.

## 구조

```
index.html              빌드 결과물 (그림이 전부 안에 들어 있어 혼자 돌아간다)
src/game.template.html  소스. 그림 자리에 __SPRITES__ 표시만 있다
assets/sprites/*.png    악어 친구 77마리 + 일반 적 10종 (연필 그림을 사진에서 잘라낸 것)
assets/bosses/*.png     보스 7종 (빨간 눈)
tools/build.py          assets를 템플릿에 심어 index.html을 만든다 (--bare OUT: 아티팩트용 본문만)
og.png / icon.png       링크 미리보기 그림, 홈 화면 아이콘
manifest.json / sw.js   홈 화면 추가(설치)용
```

소스를 고친 뒤에는 `python3 tools/build.py` 한 번.

## 게임 구성

- 흐름: 제목 → 소/중/대 → 메인화면(지도실·편성·구름·도구실·캠프파이어) → 성 8개 → 전투 → 보스전 → 결과
- 전투: 오른쪽 우리 토성, 왼쪽 위 적 토성. 지갑은 초당 14돈(+지갑 Lv.당 4, 전투 중 지갑 강화 +8). 필드의 친구는 30마리까지. 소 난이도 적 HP는 1.1배. 적은 토성에서 떨어져 내려오고, 아군은 왼쪽 끝까지 가서 적 토성을 직접 친다. 토성 HP가 0이 되면 보스전.
- 보스전: 편성 중 한 명만 골라 직접 움직인다. A·D 이동, W 점프(공중에서 한 번 더 누르면 2단 점프), Space 공격, S 특수기(화면 버튼도 됨). 점프는 짧고 빠르다 — 돌진은 2단 점프로 넘는다. 보스마다 패턴이 다르다(아래 표).
- 회차: 7번 성까지 점령하면 결과 화면의 '2-1 시작'으로 바로 2회차, 그다음 3회차. 적은 수·HP·공격 모두 2회차 2.09배(1.9×1.1)·3회차 3.08배에 수 10% 더, 친구는 +50%·+100%. 보스는 회차당 +50%만. 8번 성은 적·보스 그림이 오면 연다(`STAGES`에서 locked/hidden 제거).
- 속성: 불 ＞ 나무 ＞ 물 ＞ 돌 ＞ 불. 상성이면 2배. 불=화상, 물=둔화, 나무=묶기, 돌=기절.
- 난입: 돼지(들이받기)·새(쪼기, 날아서 땅 근접 악어가 못 닿음)·돌골램(내리찍기)이 스테이지와 상관없이 가끔 떨어진다.
- 적의 공격도 제각각: 개구리 혀(짧은 원거리), 고릴라 땅치기(3번째마다 주변 전부), 하마 물기(밀침)·멀리서 돌진, 피라냐 야금야금 3연타, 낙타 침 뱉기(원거리), 해파리 긴 촉수(원거리·둔화), 눈사람 눈덩이(원거리·둔화), 드래곤 불꽃.
- 친구의 공격 모션도 제각각: 물기·베기·찌르기·휘두르기·밀치기(적을 뒤로)·집게·주먹·뱀 채찍·돌진·내리찍기·화살·총알·레이저·물총·음표·필름·별·달빛·번개·뿌리·깃발·불꽃. `ATK_STYLE` 표에서 친구별로 고른다.
- 결과: 판이 끝나면 윗줄에 점수·별점, 아랫줄에 처치·토성 피해·소환·시간·보스 결과, 그 아래 얻은 재화(코인·숯불·오아시스·XP)와 누적 기록이 나온다. '다음 성'은 초록 버튼. '자랑하기' 카드는 ✕·닫기·바깥 터치로 닫는다. 진 판도 점수만큼 코인·XP를 준다. '자랑하기'로 결과를 한 장 그림으로 만들어 카톡 등에 보낼 수 있다(안드로이드 크롬).
- 소리·진동: 효과음과 스테이지별 배경음악은 전부 코드로 합성한다(파일 없음). 배경음악은 장면마다 한 번 미리 렌더링해(OfflineAudioContext) 한 덩어리로 반복 재생하고, 오디오 버퍼는 'playback'으로 크게 잡아 안드로이드에서 지직거리지 않게 했다. 끝단에 리미터. 진동은 안드로이드에서 울린다. 설정과 전투 화면에서 끌 수 있다.
- 손맛: 큰 공격은 순간 멈춤·흔들림, 데미지 숫자, 적은 뒤집히며 튕겨 나가고 코인이 지갑으로 날아간다.
- XP: 판이 끝날 때마다 쌓인다. 쓰는 곳은 편성 화면 — 친구 카드의 노란 버튼으로 레벨업(레벨당 +10%, 최대 20, 100XP×레벨). 누적 XP는 플레이어 레벨로 환산해 지갑 맨 뒤 보라 동그라미에 숫자로 보인다(Lv.2=100, Lv.3=300, Lv.4=600 …).
- 기본 친구: 맨 앞의 '악어'(30돈)가 제일 싸다. 화난악어·괴물악어·폭딜악어는 앞쪽 범위 공격.
- 토성 대포: 전투 중 게이지가 차면(26초) 우리 토성이 광선을 쏴 모든 적에게 150 피해 + 밀어내기 + 기절. 오아시스가 있으면 즉시 충전.
- 적 출현: 초반엔 드문드문, 중반(30~72%)에 몰려오고(무더기 낙하도 이때), 후반엔 다시 뜸하다. 정해진 수가 다 나와도 '증원'이 천천히 계속 온다. 아주 가끔(3%) 긴 숨 고르기. 중간 보스 '큰 ○○'는 절반이 넘게 나온 뒤(50~85%), 그리고 35초는 지나야 나오며 앞뒤로 졸개 3마리를 데려온다. 2번 성부터 이전 성 적이 가끔(7%) '강화 ○○'(HP 2배·공격 1.4배·붉은 기운)로 섞인다.
- 보스 분노: HP 50% 이하에서 붉어지고 1.3배 빨라지며 하늘에서 돌·물방울이 떨어진다.
- 특수기(보스전 S키/버튼, 8초): 택배=택배 폭탄(1초 뒤 4), 회복 친구=회복, 돈 친구=동전 투척, 잠꾸러기=한숨 자기(하트 회복), 속성=속성 폭발, 날개=급강하, 화살=화살비, 포탄=포탄 투하(3), 총=3연발, 회전=회오리(2+2·무적), 속도 120↑=순간 이동(보스 뒤), 키 100↑=내리 찍기(3), 2연타=연속 공격(1×3), 범위=크게 치기(3), 공격 60↑=지면 강타, HP 300↑=버티기, 그 외=돌진 베기.
- 캠프파이어: 실루엣이 먼저 보이고 공개. 슈퍼·레어·특별은 보라 불꽃.
- 탐험: 도구실에서 친구를 보내면 1시간 뒤(앱을 꺼도 흐름) 코인·숯불, 가끔 오아시스.
- 이벤트(구름): 드래곤 침공. 하루 한 번, 날아다니는 드래곤 떼, 보상 오아시스. 드래곤 그림은 아직 드래곤악어로 대신.
- 도감 보상: 새 친구 10마리마다 숯불 1, 슈퍼·레어·특별 등급 완성 시 숯불 3.
- 첫 플레이 힌트: 첫 전투와 첫 보스전에 말풍선 안내.
- 홈 화면 추가: 첫 점수를 받으면 안내 팝업이 뜬다(안드로이드 크롬은 '바로 추가', 아이폰은 공유→홈 화면에 추가). `manifest.json`·`sw.js`가 설치용이다. 자랑하기 카드와 공유 글에는 게임 링크가 들어간다('링크 복사'도 있음).
- 저장: 코인·강화·점령·친구·편성·기록은 브라우저(localStorage)에 자동 저장된다. 설정 화면의 '저장 코드 복사 / 코드 불러오기'로 다른 기기로 옮길 수 있다. 서버 없음.

## 숫자 고치는 곳

전부 `src/game.template.html` 위쪽 표에 모여 있다.

- `UNITS` — 친구 77마리의 가격·HP·공격·속도·사거리·공격 방식
- `ENEMY` — 적 10종
- `STAGES` — 성별 적 수(소/중/대)·토성 HP·배경
- `BOSSES` / `BOSS_HP` / `PAT` — 보스 크기·HP·패턴
- `DIFF`, `RAMP`, `roundEnemy/roundAlly/roundReward` — 난이도·회차 배율

## 그림 추가하는 법

흰 종이(또는 흰 배경)에 한 마리씩 그려서 사진을 보내면 잘라서 `assets/`에 넣고, 표에 한 줄 추가하면 된다. 보스는 눈을 빨갛게.

# 악어악어 점령

아이가 연필로 그린 악어들이 토성을 지키는 가로형 타워디펜스. 냥코대전쟁식 웨이브 전투 끝에 직접 조작하는 보스전이 붙어 있다.
한 장짜리 웹 게임(`index.html`)이라 어디서든 열면 바로 돌아간다. 폰은 옆으로 돌려서.

## 바로 플레이

`index.html`을 브라우저로 열면 끝. GitHub Pages를 켜면 링크로도 열 수 있다.

## 구조

```
index.html              빌드 결과물 (그림이 전부 안에 들어 있어 혼자 돌아간다)
src/game.template.html  소스. 그림 자리에 __SPRITES__ 표시만 있다
assets/sprites/*.png    악어 친구 76마리 + 일반 적 10종 (연필 그림을 사진에서 잘라낸 것)
assets/bosses/*.png     보스 7종 (빨간 눈)
tools/build.py          assets를 템플릿에 심어 index.html을 만든다
```

소스를 고친 뒤에는 `python3 tools/build.py` 한 번.

## 게임 구성

- 흐름: 제목 → 소/중/대 → 메인화면(지도실·편성·구름·도구실·캠프파이어) → 성 8개 → 전투 → 보스전 → 결과
- 전투: 오른쪽 우리 토성, 왼쪽 위 적 토성. 적은 토성에서 떨어져 내려오고, 아군은 왼쪽 끝까지 가서 적 토성을 직접 친다. 토성 HP가 0이 되면 보스전.
- 보스전: 편성 중 한 명만 골라 직접 움직인다. A·D 이동, W 점프, Space 공격(화면 버튼도 됨). 보스마다 공격 패턴이 다르다.
- 회차: 성 7개를 다 점령하면 2회차 → 3회차. 적도 세지고 친구도 세진다(+50%/회차).
- 속성: 불 ＞ 나무 ＞ 물 ＞ 돌 ＞ 불. 상성이면 2배. 불=화상, 물=둔화, 나무=묶기, 돌=기절.
- 난입: 돼지·새·돌골램이 스테이지와 상관없이 가끔 떨어진다. 새는 날아서 땅 근접 악어가 못 닿는다.

| 성 | 배경 | 적 | 보스 |
|---|---|---|---|
| 1 | 늪지대 | 개구리(물) | 왕개구리 — 혀, 내려찍기, 연속 점프 |
| 2 | 정글 | 고릴라(나무) | 킹고릴라 — 손바닥, 바위 던지기, 가슴 두드리기 |
| 3 | 호수 | 하마(돌) | 대왕하마 — 물기, 돌진, 포효 |
| 4 | 강 | 피라냐(물) | 왕피라냐 — 물대포, 물기, 물방울 비 |
| 5 | 사막 | 낙타(돌) | 왕낙타 — 내리찍기, 발구르기, 침 뱉기 |
| 6 | 바다 | 해파리(물·공중) | 왕해파리 — 독침, 촉수, 떠다니기 |
| 7 | 설원 | 눈사람(물·눈덩이 원거리) | 왕눈사람 — 눈덩이, 화염방사, 머리 굴리기 |
| 8 | 겁~나 성 | (그림 대기) | (그림 대기) |

## 숫자 고치는 곳

전부 `src/game.template.html` 위쪽 표에 모여 있다.

- `UNITS` — 친구 76마리의 가격·HP·공격·속도·사거리·공격 방식
- `ENEMY` — 적 10종
- `STAGES` — 성별 적 수(소/중/대)·토성 HP·배경
- `BOSSES` / `BOSS_HP` / `PAT` — 보스 크기·HP·패턴
- `DIFF`, `RAMP`, `roundEnemy/roundAlly/roundReward` — 난이도·회차 배율

## 그림 추가하는 법

흰 종이(또는 흰 배경)에 한 마리씩 그려서 사진을 보내면 잘라서 `assets/`에 넣고, 표에 한 줄 추가하면 된다. 보스는 눈을 빨갛게.
